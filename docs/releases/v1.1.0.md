# 战双剧情问答 v1.1.0

这一版主要修「出处点不开」，并让回答边生成边出现。语料不需要重抓。

## 你会看到的变化

### 出处当次就能点开，而且写明是第几关

以前刚答完的那条回答里，正文中的出处是灰的、点不动，非得刷新页面才变可点；好感度剧情的出处（章节名里带斜杠）更是整条都打不开。

现在答完即可点，标签直接写到具体关卡，例如【好感度剧情／赛琳娜·希声/好感剧情／袂拥】。点开就是这一关的原文。

### 文字边生成边出现

以前是盯着进度条等十几秒，最后整段答案一次性蹦出来。

现在大约 4 秒就开始出字，等待小窗同时告诉你它在做什么——检索台词、读原文、翻章节，而不是只有一个秒数在跳。

### 追问只带摘要，不再重发全文

记得最近 10 轮对话，每轮压成一句话摘要。同样两轮前文，从约 2400 字降到几十字。刷新页面也不会丢。

### 页头新增设置（齿轮图标）

检索步数和回答字数都能自己调：步数 2~10，字数 200~2000。拖动滑杆时会实时显示预计耗时和花费，保存后立刻生效，不用重启。

默认 7 步——这是历史提问步数的中位数，多数问题够用。

### 出处的可靠性有了自动检查

每条【分类／章节／关卡】都必须能在剧情库里对上真实关卡，对不上的会被标成「未核实」并在点击时说明原因。这类检查现在进入发布前的自动测试，不会再悄悄退回去。

## 升级方式

便携版：解压覆盖到原目录即可，语料库、API Key 和问答历史都不会动。

源码：`git pull` 后直接启动，不需要重新抓语料。（第一次用才需要按 README 跑一次 `bootstrap` 建库。）
